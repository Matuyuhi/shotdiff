## 2024-07-22 - Optimizing Tight Pixel Loops in Rust Image Processing
**Learning:** In the `shotdiff` codebase, using the `image` crate's `.pixels()` iterator introduces significant overhead due to abstractions. Iterating over the underlying raw byte slice via `.as_raw().chunks_exact(4)` is much faster. Furthermore, floating-point arithmetic for luma calculations in tight pixel loops is a severe bottleneck. Using integer approximations like `(77 * r + 150 * g + 29 * b) >> 8` combined with explicit dereferencing for mutable chunk iteration yields measurable speedups while preserving exact behavior.
**Action:** When optimizing image processing loops in Rust, prefer accessing raw buffers with `chunks_exact` and `chunks_exact_mut` over higher-level iterators. Replace floating-point operations in hot paths with equivalent integer arithmetic approximations whenever precision requirements permit.
